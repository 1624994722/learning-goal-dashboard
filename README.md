# 学习目标管理台 (Learning Goal Dashboard)

一个专门管理**有终点、有总量**学习目标的在线管理台（如"背完 2000 个单词"、"读完一本 440 页的书"），不是无限期的习惯打卡。

## 在线使用

- **在线页面**: https://workbuddy.link/p/Twyg3XtyUcpdG3Lzct9RfP
- 数据通过资料库数据表在线存储，换设备/换浏览器数据都在

## 功能特性

### 目标管理
- 名称、单位、总量、截止日、配色
- 选填：最可能拦住你的障碍 + "如果它出现，我就……"对策预案
- 每日建议量 = 剩余量 ÷ 剩余天数，打卡时预填但允许修改

### 核心指标
- **完成率**、**连续打卡天数**、**预计完成日**
- 预计完成日按近 7 天平均速度推算，与截止日比较显示提前/拖后，样本不足显示"暂无推算"

### 休息日机制
- 每周从周一起自动拥有 1 个休息日：本周第一次漏打卡不中断连续，第二次才断
- 昨日漏打卡的目标今日自动置顶（温和黄卡解释休息日 / 红卡滚入今日）
- 逾期目标显示天数，提供"立即打卡"和"调整计划"两个出口

### 打卡与补记
- 一天可记录多次，支持选填分钟数
- 可补记最近 6 天，带"补"标，按真实日期参与连续天数和推算

### 四个 Tab
1. **今日** — 新建目标、今天要处理、可直接打卡的目标卡
2. **看板** — 进度环、三个核心数字、预案、最近 10 条可删除记录、近 14 天投入分钟堆叠柱状图（手写 SVG）
3. **周报** — 周一至周日汇总 + 上周环比 + 历史周查看 + 保持/问题/尝试/下周预案四栏 + 一键生成周报文本
4. **我的** — 同步状态、手动重新同步、清空示例/全部、添加到手机主屏幕指引

### 视觉与适配
- 冷白底、米白渐变、绿色成功、红色逾期、琥珀色休息日
- 目标达成彩带动效，图标全部内联 SVG
- 手机底部四 Tab 单列 / 平板顶部导航 / 电脑左侧边栏多栏

## 技术说明

- 单文件 HTML（`src/index.html`），零构建、零外部依赖
- 打卡数据存储于线上数据表，页面读写即时同步
- 页面加载先渲染界面再拉取数据，读写失败有提示并可重试
