## 它解决什么问题

常见的习惯打卡工具都在记录「今天有没有做」，但学习目标本质上是有终点的：**总量明确、有截止日、关心还差多少和什么时候能完成**。

这个管理台的所有设计都围绕这一点：

| 传统打卡 | 本项目管理台 |
|---|---|
| 今天打卡了吗 | 还剩多少、按当前速度什么时候完成 |
| 连续天数断了就焦虑 | 每周有一天容错额度，漏一天不断链 |
| 记录流水 | 每日建议量 = 剩余量 ÷ 剩余天数 |
| 事后看日历 | 近 7 天均速推算预计完成日，与截止日对比 |

## 功能特性

### 目标管理
- 名称、单位、总量、截止日、配色
- 选填「最可能拦住你的障碍」+「如果它出现，我就……」的对策预案
- 每日建议量自动计算，打卡时预填但允许修改

### 核心指标
- **完成率** · **连续打卡天数** · **预计完成日**
- 预计完成日按近 7 天平均速度推算，与截止日比较显示提前 / 拖后；样本不足时显示「暂无推算」而非乱猜

### 休息日机制
- 每周从周一起自动拥有 1 个休息日：本周第一次漏打卡**不中断**连续，第二次才断
- 昨日漏打卡的目标今日自动置顶——温和黄卡解释休息日，或红卡滚入今日
- 逾期目标显示逾期天数，提供「立即打卡」与「调整计划」两个出口

### 打卡与补记
- 一天可记录多次，支持选填投入分钟数
- 可补记最近 6 天，带「补」标，按真实日期参与连续天数与速度推算

### 番茄钟
- 悬浮玻璃质感计时器，专注 / 短休 / 长休三模式，各自色彩语义
- 结束后提示记录到当前目标，把「坐下来的时间」和「推进了多少」连起来
- 设置项可折叠，不占主界面

### 文档导入 → 任务计划
- 导入 `.md` / `.xlsx`，自动生成结构化任务计划
- 支持点击上传与拖拽上传（拖拽时高亮反馈）
- 解析出任务名称、描述、优先级（高/中/低 → 红/琥珀/青）、预计完成时间
- 落库前提供预览列表，可逐个编辑或删除，确认后才写入
- 空文档、损坏文件、格式不支持、解析引擎加载失败等均有明确提示

### 五个 Tab
1. **今日** — 新建目标、导入文档、今天要处理的事、可直接打卡的目标卡
2. **番茄钟** — 计时器与近期专注记录
3. **看板** — 进度环、三个核心数字、预案、最近 10 条可删除记录、近 14 天投入分钟堆叠柱状图（手写 SVG）
4. **周报** — 周一至周日汇总 + 上周环比 + 历史周查看 + 保持/问题/尝试/下周预案四栏 + 一键生成周报文本
5. **我的** — 同步状态、手动重新同步、数据导入导出、清空数据、添加到手机主屏指引

### 视觉与动效
- 米白暖中性主题；侧边栏为暖墨渐变 + 极光氛围光 + 磨砂玻璃导航轨
- GSAP + Anime.js 动效系统：滚动入场、数字滚动、切换过渡、达成彩带
- 三源 CDN 回退加载；`prefers-reduced-motion` 下自动降级为无动画
- 响应式：手机底部玻璃导航 / 平板顶部导航 / 桌面左侧边栏

## 技术说明

- **架构**：单个 HTML 文件，原生 JS（ES5 语法为主，兼容老浏览器），无框架、无打包器
- **状态层**：`localStorage`（goals / logs / notes）为本地真相源，云端同步为增强项
- **动效**：GSAP + Anime.js 通过 CDN 加载，采用「包装全局函数」方式接入，不侵入业务逻辑；CDN 不可用时自动跳过所有动画，功能不受影响
- **图标**：全部内联 SVG，无图标字体、无外部图片请求
- **可访问性**：语义化标签、`aria-*` 标注、键盘可达、焦点返回、对比度满足 WCAG AA

### 关于云端同步

代码内保留了 WorkBuddy 资料库数据表的双向同步实现（`pullRemote` / `pushRemote` / `mergeRemote`），在 WorkBuddy 环境中运行时数据换设备、换浏览器都在。

**Fork 后请注意**：该云端能力依赖 WorkBuddy 平台运行时，脱离该环境时会自动降级为纯 `localStorage` 本地存储——应用功能完整可用，只是数据存在当前浏览器里。若要接自己的后端，替换 `sync` 相关函数即可（同步层与业务逻辑是解耦的）。

## 部署

```bash
# Cloudflare Workers 静态资产
npm i -g wrangler
wrangler login
wrangler deploy
```

也可以直接把 `src/index.html` 丢到任意静态托管（GitHub Pages / Vercel / Netlify / 对象存储）上，无需任何配置。

> 提示：`*.workers.dev` 域名在国内网络环境下可能无法正常访问，建议绑定自定义域名。

## 开发约定

- 修改主应用只改 `src/index.html`，不要引入构建步骤
- 新增颜色请走 `:root` 里的 CSS 变量，侧边栏相关用 `--side-*` 令牌组
- 新增交互若无障碍要求，请补 `aria-*` 与键盘可达性
- 动效一律考虑 `prefers-reduced-motion` 降级
